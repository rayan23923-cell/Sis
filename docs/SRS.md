# SRS — Iraqi University SIS (مسودة أولية v0.1)

- الحالة: مسودة للمراجعة (المرحلة الأولى، Discovery)
- التاريخ: 2026-11-18
- المنصة المعتمدة: Laravel 13 + Inertia v2 + Vue 3 + MariaDB 11.8 LTS، ببنية مستودع FileNest (ADR-001)
- المراجع: وثيقة المرحلة الأولى، `ADR.md`، `POC_TEST_PLAN.md`

> قاعدة حاكمة: أي متطلب يحمل الوسم **[OPEN-Qn]** يعتمد على جواب رسمي من الجامعة (القسم E في وثيقة المرحلة الأولى). لا يُنفَّذ منطق أكاديمي بقيم افتراضية في الإنتاج.

---

## 1. المقدمة

### 1.1 الغرض
تحدد هذه الوثيقة المتطلبات الوظيفية وغير الوظيفية لنظام معلومات الطلبة (SIS) الذي يستبدل النظام الحالي في جامعة عراقية، ويعمل على خوادم الجامعة (On-Premises).

### 1.2 النطاق
- 10,000 إلى 25,000 طالب، عدد كليات وأقسام وموظفين قابل للتهيئة.
- نظامان دراسيان متوازيان: مسار بولونيا (ECTS) والنظام التقليدي (فصلي/سنوي).
- تكامل مع Koha وMoodle وERPNext (إن وُجد) وKeycloak، وتصدير/استيراد للأنظمة الوزارية.
- خارج النطاق في الإصدار الأول: المالية الكاملة (تبقى في ERPNext أو النظام المالي الحالي)، الموارد البشرية، LMS (يبقى Moodle).

### 1.3 التعاريف
| المصطلح | المعنى |
|---|---|
| المنهج (Curriculum Version) | إصدار مؤرخ من الخطة الدراسية لبرنامج، يُسند للطالب عند القبول |
| السياسة (Policy) | قاعدة أكاديمية مُصدَرة ومؤرخة (درجات، معدل، ترفيع...) |
| لقطة السياسة | معرف السياسة وإصدارها المخزنان مع كل نتيجة محتسبة |
| الأمر الإداري | قرار رسمي مرقم ومؤرخ يغير حالة طالب أو نتيجة |
| الدور الامتحاني | الدور الأول أو الثاني أو ما تحدده التعليمات |
| الترقين | إنهاء قيد الطالب وفق التعليمات |

### 1.4 أصحاب المصلحة
رئاسة الجامعة، عمادات الكليات، رؤساء الأقسام، اللجان الامتحانية، التسجيل وشؤون الطلبة، التدريسيون، الطلبة، مركز الحاسبة، المكتبة المركزية، الشعبة المالية، قسم ضمان الجودة.

## 2. الوصف العام

### 2.1 الأدوار
| الدور | النطاق | أمثلة صلاحيات |
|---|---|---|
| مدير النظام | الجامعة | الإعدادات، المستخدمون، التكاملات |
| مسؤول القواعد الأكاديمية | الجامعة | إنشاء وإصدار السياسات بعد الاعتماد |
| مسجل الجامعة | الجامعة | الأرقام الجامعية، الأوامر الإدارية المركزية |
| عميد / معاون عميد | كلية | المصادقة، التقارير، الأوامر على مستوى الكلية |
| مسجل الكلية | كلية | بيانات الطلبة، التسجيل |
| رئيس القسم | قسم | المناهج، توزيع التدريسيين، المصادقة الأولى |
| اللجنة الامتحانية | كلية/قسم | إدخال ومراجعة وإغلاق النتائج |
| التدريسي | شعبه فقط | إدخال درجات المكونات |
| الطالب | نفسه | العرض، طلبات الخدمات، التسجيل إن سُمح |
| مدقق | حسب التكليف | قراءة فقط مع سجل التدقيق |

### 2.2 القيود
- C-01: مصدر مفتوح، والكود ملك الجامعة.
- C-02: تشغيل داخلي، والوصول الخارجي عبر HTTPS فقط خلف WAF.
- C-03: العربية لغة أساسية (RTL)، والإنجليزية ثانوية (LTR).
- C-04: المنطقة الزمنية Asia/Baghdad، والعملة IQD.
- C-05: لا يُعتبر النظام بديلاً لأي نظام وزاري إلزامي دون موافقة رسمية.
- C-06: بنية الكود مطابقة لـ FileNest (Laravel، `app/`، `resources/js/Pages`، `deploy/`، `tests/`).

### 2.3 الافتراضات (تُراجع)
- A-01: يوجد معرف وطني أو بديل يمنع تكرار الطالب **[OPEN-Q13]**.
- A-02: كل طالب مرتبط ببرنامج واحد نشط في وقت واحد، مع تاريخ برامج سابق.
- A-03: الدرجات رقمية من 100 قبل التحويل لتقدير **[OPEN-Q2]**.
